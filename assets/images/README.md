# Images NLT.Visual

## Important

Les fichiers actuels sont des visuels abstraits de démonstration destinés à vérifier la composition du site. Ils doivent être remplacés par les photographies réelles de NLT.Visual avant publication.

## Dossiers

- `hero/` : image principale, portrait vertical et détail.
- `matchday/` : couverture de match.
- `portraits/` : portraits joueurs.
- `goalkeepers/` : gardiens.
- `clubs/` : équipe, staff, structures, supporters, partenaires.
- `training/` : entraînements.
- `lifestyle/` : tunnel, vestiaire, arrivée et coulisses.
- `projects/` : six images par mini-reportage.
- `about/` : portrait de Nolann.
- `thumbs/` : versions légères utilisées dans les grilles.

## Nommage

Préférer :

```text
photographe-football-lens-nom-club-adversaire-01.webp
shooting-joueur-football-lille-portrait-01.webp
photographe-gardien-hauts-de-france-plongeon-01.webp
```

Éviter :

```text
IMG_3828.webp
final-final-2.webp
photo1.webp
```

Le nom de fichier reste secondaire face au contenu de la page, mais il facilite la maintenance et donne un signal descriptif cohérent.

## Recadrage

Tester chaque image dans trois contextes :

1. desktop large ;
2. mobile 390 px ;
3. lightbox plein écran.

Ne jamais placer un visage important au bord extrême si l’image est affichée avec `object-fit: cover`.

## Textes alternatifs

Décrire ce qui est utile à une personne qui ne voit pas l’image : action, sujet, contexte et lieu lorsque ces informations sont connues.

Bon exemple :

```text
Gardien en extension sur sa droite pendant un match de football à Lens.
```

Mauvais exemple :

```text
Belle photo de football NLT.Visual photographe Lens.
```

Le texte alternatif n’est pas un emplacement pour empiler des mots-clés.
